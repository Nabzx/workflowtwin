# Changelog

All notable changes to WorkflowTwin are documented here.

## [1.0.0] - 2026-07-19

### Recruiter-facing fictional pilot

- Added an eight-page React and TypeScript product covering workflow, evidence, opportunity,
  simulation, human-approved pilot, audit, and engineering decisions.
- Added compact typed demo APIs, a Zod-validated frontend client, structured request observability,
  health/readiness, system status, and guarded deterministic reset.
- Added editable administrative drafts, atomic approval, fictional task creation, idempotency,
  rollback, audit verification, and visible authority boundaries with no send capability.
- Added frontend unit/component tests, Playwright workflow and safety tests, Axe accessibility checks,
  responsive layouts, light/dark/system themes, and route-level code splitting.
- Added complete Docker Compose, unified container, Render blueprint, and verified Vercel deployment.
- Added architecture diagrams, screenshots, case study, demo script, interview notes, and release
  validation documentation.

### Known limitations

- All customers, records, research, actions, and results are fictional or synthetic.
- Public state is ephemeral and shared; it is not production multi-user infrastructure.
- Authentication, real integrations, external communication, and clinical decisions are absent by
  design.
- Counterfactual results are planning estimates, not realised impact.
- PM4Py's AGPL licence requires review before commercial distribution.
